# 看板视觉规范

看板各页共用一份母版：`dashboard-shell.css`。字号、行高、页眉高度、左右页边距都在这里。新页面必须引入它，不要在页面里再写死一套字号。

配色：白底、浅灰页面、蓝灰字和强调。不要用红绿做涨跌或交易高亮。主人在工位上看，页面不能像炒股软件。

## 页眉（四页必须重合）

切换 Tab 时，图标、标题基线和底部分隔线的 y 不能动。四页共用这一套页眉。申赎两融内部顺序为 ETF 份额申赎、两融余额与指数；资金观察仅保留盘中成交及成交历史。宽屏申赎总量与单只份额并排，窄屏上下排列。国家队持仓与 ETF 明细不再展示。

| 项 | 值 |
|---|---|
| 图标 | 38×38 |
| 页标题 | 18px / 26px / 字重 600 |
| 页副标题 | 14px / 22px / 字重 400，完整显示，不强制省略号 |
| 左右页边距 | 宽度 &lt;700px 为 16px；≥700px 为 24px |
| 顶栏按钮 | 高 44px（口径说明、刷新）。不要改成筛选控件的 36px |
| 标题栏 | 窄屏最小高 120px，宽屏最小高 68px |
| 导航行 | 高 66px |

副标题在 390px 宽必须仍是一行。现用文案：

- 资金观察：宽基 ETF · 盘中活跃度与主动买卖方向
- 申赎两融：ETF 申赎 · 沪深两融 · 日度数据
- 期指持仓：中信期货(代客) · CFFEX 前20会员
- 全球风险：利率条件与融资成本 · 读最新值与历史
- 份额申赎：宽基 ETF · 全市场申赎，非国家队专属

加长副标题之前，先在 390px 量一行高度。换行会把图标和分隔线顶下去。

## 节标题与间距

标题和说明都在卡片外面，内容在卡片里面。四页用同一组间距，写在 `dashboard-shell.css`。

| 间距 | 值 |
|---|---|
| 顶栏分隔线到第一节标题 | 16px |
| 节标题到说明 | 4px |
| 说明行高 | 20px；宽度 &lt;700px 时说明区固定两行（40px），短说明不把内容顶上去 |
| 窄屏控件行 | 宽度 &lt;700px 时，只有带按钮或下拉的节才在说明下留 44px。没有控件的节不留空行 |
| 说明到内容 | 12px |
| 节与节之间 | 24px |

说明文字一律 13px / 20px / 字重 400 / `--muted`。状态词如「休市（已收盘）」也用这一档，分隔线可以留。不要再给某一页的 `#st` 单独加 margin、字号或加粗。

右侧只放可点击控件。窄屏上说明在标题下换行；控件仍要能点。

## 七ETF分时纵轴

七张涨跌幅图共用选中同日的尺度：只使用相对昨收的有效涨跌幅，取七只最大绝对值留10%空间后向外取整（最低±0.5%，上限按0.5个百分点取整），上下对称、零线居中、五个刻度。实时刷新和历史切日重新计算；缺失值不按0、其他日期不混入。ETF价格只作为悬浮字段，不添加隐藏价格序列。成交额柱图和MACD各自尺度保持，不与涨跌幅共轴。

## 改界面时核对

- 1440 和 390 各截四页顶栏。图标 y、标题 y、分隔线 y 各页相同（1440 分隔线 135，390 为 187）。
- 用 getBoundingClientRect 量四页：顶栏到第一节标题、标题到说明、说明到内容、节与节之间。1440 上第一节的标题、说明、内容要对齐（±1px）。390 上有控件的节可以更低，没有控件的节不要为了对齐而留空。
- 节说明在标题左下方，右侧没有纯文字说明。
- 没有新增红绿涨跌色。
- 没有在单页里写一套新的字号或间距。
