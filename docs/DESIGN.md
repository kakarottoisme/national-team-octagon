# 看板视觉规范

四页共用一份母版：`dashboard-shell.css`。字号、行高、页眉高度、左右页边距都在这里。新页面必须引入它，不要在页面里再写死一套字号。

配色：白底、浅灰页面、蓝灰字和强调。不要用红绿做涨跌或交易高亮。主人在工位上看，页面不能像炒股软件。

## 页眉（四页必须重合）

切换 Tab 时，图标、标题基线和底部分隔线的 y 不能动。

| 项 | 值 |
|---|---|
| 图标 | 38×38 |
| 页标题 | 18px / 26px / 字重 600 |
| 页副标题 | 14px / 22px / 字重 400，完整显示，不强制省略号 |
| 左右页边距 | 宽度 &lt;700px 为 16px；≥700px 为 24px |
| 顶栏按钮 | 高 44px（口径说明、刷新）。不要改成筛选控件的 36px |
| 标题栏 | 窄屏最小高 120px，宽屏最小高 68px |
| 导航行 | 高 66px |

副标题在 390px 宽必须仍是一行。现用文案：

- 资金观察：宽基 ETF · 盘中活跃度与主动买卖方向
- 两融余额：沪深两市 · 日度数据
- 期指持仓：中信期货(代客) · CFFEX 前20会员
- 全球风险：利率条件与融资成本 · 读最新值与历史

加长副标题之前，先在 390px 量一行高度。换行会把图标和分隔线顶下去。

| 角色 | 字号 | 行高 | 字重 |
|---|---|---|---|
| 页标题 | 18px | 26px | 600 |
| 页副标题 | 14px | 22px | 400 |
| 节标题 | 16px | 24px | 600 |
| 节说明 | 13px | 20px | 400 |
| 正文 | 14px | 22px | 400 |
| 表头 | 13px | 20px | 500 |
| 表体 | 14px | 22px | 400 |
| 指标数字 | 26px | 32px | 600 |
| 指标说明 | 13px | 20px | 400 |
| 筛选控件 | 14px | 22px | 500 |
| 筛选选中 | 同控件 | 同控件 | 600 |

筛选控件（芯片、分段、下拉）：高 36px，左右内边距 12px，圆角 10px，边框 `#ccd5df`，白底。选中：底 `#edf3fc`，边 `#9db8db`，字 `#325b90`。

## 节标题

说明文字在标题左侧、标题下面一行。右侧只放可点击控件（按钮、下拉、筛选）。日期范围、分组芯片可以留在标题下方整行，但不要把「截至…」「点击一行…」「最近采集…」放到右边。

窄屏上说明可以在标题下换行；控件仍要能点。

## 改界面时核对

- 1440 和 390 各截四页顶栏。图标 y、标题 y、分隔线 y 四页相同。
- 节说明在标题左下方，右侧没有纯文字说明。
- 没有新增红绿涨跌色。
- 没有在单页里写一套新的字号。
